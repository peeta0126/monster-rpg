# 숲 밸런스 baseline

소란도(STEP 1) 이후의 실측치. **STEP 3(채집망) 이후 재조정할 때 이 표와 비교한다.**

수치 자체는 아직 확정이 아니다. 지금 목표는 균형이 아니라 구조다 — 채집망이 수확에
천장을 씌우기 전까지는 "많이 가져올수록 좋다"가 무조건 참이라, 여기서 균형을 맞추면
STEP 3 이후에 두 번 튜닝하게 된다.

## 측정 방법

`npx tsx scripts/sim/forestBalance.ts` — 구역·전략별 20,000회.
시뮬은 게임과 **같은 생성기**(`forest/dungeon.ts`)로 그래프를 만들고 실제로 걸어간다.
전략은 갈림길에서 무엇을 고르는가다.

- `avoid` — 소란이 덜 오르는 쪽
- `random` — 무작위
- `greedy` — 소란이 더 오르는 쪽

**반입** = 강제 퇴각 시 회수율 50%(STEP 4 정산)를 반영해 실제로 집에 가져오는 양.

## 2026-08-11 (A) · 소란도 도입 직후

노드 5~7개, 시작 소란 0, 갈림길 45%가 외길, 구간 계수 1.0 / 1.3 / 1.6 / 2.0.

| 구역 | avoid 재료 | greedy 재료 | 최고 소란 (avoid→greedy) | 강제 퇴각 (greedy) |
|---|---|---|---|---|
| 얕은 숲 | 2.7 | 3.4 | 48 → 64 | 5.6% |
| 깊은 숲 | 6.6 | 8.4 | 48 → 64 | 5.4% |
| 고대 숲 | 11.1 | 13.9 | 48 → 64 | 5.4% |

반입 격차(얕은 숲) **+22.7%**. 소란도 도입 전 원래 수확은 2.84 / 6.95 / 11.65 였다.

문제: 갈림길의 절반 이상이 외길이라 **회피도 탐욕도 제대로 못 했다.** 최고 소란이
어느 쪽으로 굴려도 48~64 에 몰려 다이얼의 위아래 끝을 아무도 보지 못했다.

## 2026-08-11 (B) · 분기 보장 + 시작 소란 + 런 길이 + 주인 각성 (현재)

노드 8~10개, 시작 소란 0 / 15 / 30, **갈림길 최소 2개 보장**(주인 앞 복도만 예외),
주인은 **깨우는 순간**(판정 전) 소란 +30, 구간 계수 그대로.

| 구역 | 전략 | 재료 | 반입 | 최고 소란 | 강제 퇴각 |
|---|---|---|---|---|---|
| 얕은 숲 | avoid | 3.2 | 3.22 | 40 | 0.0% |
| | random | 4.8 | 4.73 | 65 | 1.1% |
| | greedy | 6.2 | 5.61 | 94 | 20.8% |
| 깊은 숲 | avoid | 8.3 | 8.35 | 42 | 0.0% |
| | random | 12.7 | 12.44 | 71 | 3.8% |
| | greedy | 16.4 | 12.87 | 98 | 44.4% |
| 고대 숲 | avoid | 14.9 | 14.90 | 47 | 0.1% |
| | random | 23.0 | 21.49 | 79 | 11.2% |
| | greedy | 27.5 | 18.12 | 99 | 70.0% |

반입 격차: 얕은 **+74.0%** · 깊은 **+54.2%** · 고대 **+21.6%** (전부 탐욕 우세).

### 읽는 법

격차가 A(+22.7%)보다 **벌어진 것이 정상이다.** 외길일 때는 아무도 자기 전략을 실행할
수 없어서 두 값이 인위적으로 붙어 있었다. 이제 회피는 최고 소란 40 에서 멈추고,
탐욕은 94~99 까지 올라 최상위 배수 구간에 실제로 닿는다 — 선택이 생기자 결과가 갈렸다.

주인 각성(+30 을 판정 전으로)은 격차를 조금 좁혔다(74.0 / 54.2 / 21.6 ← 76.6 / 62.2 / 27.9).
회피 쪽이 낮은 소란에서 올라오느라 구간을 한 칸 더 뛰어서 이득이 크고, 탐욕은 이미
천장이라 더 못 오르기 때문이다. 의도한 건 포획 확률 쪽이었는데 수확에서도 자정 작용이 났다.

남은 불균형의 원인은 하나다. **수확에 천장이 없다.** 회피의 대가(수확 감소)는 즉시
치러지는데, 탐욕의 대가(퇴각 위험)는 확률이라 기대값에서 희석된다. 고대 숲에서
격차가 제일 작은 것(+21.6%)이 그 증거다 — 퇴각률 70%가 실제로 물어뜯고 있다.

채집망이 12칸에서 막으면 탐욕의 초과 수확이 잘려 나가고 퇴각 위험만 남는다.
**목표는 STEP 3 이후 격차 ±10% 안이다.**

## 한 판 소요 시간

`npx playwright test --config design/playwright.config.ts -g "measureForest"`

버튼이 뜨자마자 누르는 **기계 시간** 기준. 사람이 읽는 시간은 빠져 있다.

| 구역 | 한 판 | 노드 | 노드당 |
|---|---|---|---|
| 얕은 숲 | 38.0초 | 10 | 3.8초 |
| 깊은 숲 | 35.9초 | 9 | 4.0초 |
| 고대 숲 | 33.2초 | 8 | 4.1초 |

노드당 읽기 시간을 5초로 잡아도 한 판 **2~3분**이다. 포획을 3회까지 시도하는 판을
넉넉히 얹어도 4분을 넘지 않는다. 브라우저 게임의 10분 상한 안이라 8~10 노드를 유지한다.
